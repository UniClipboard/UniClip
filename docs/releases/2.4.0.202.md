## Remaining release steps

1. Record physical-device acceptance for the selected Alpha build, including background and foreground transitions.
2. Commit and push the prepared metadata and changelogs to `main`.
3. Run `release.yml` on the latest `main` with `platforms=both`.
4. Let Prepare verify build 202 against App Store Connect and origin tags.
5. If App Store Connect has consumed build 202 or higher, bump past its highest number and regenerate the notes before retrying.
6. Confirm both builds succeed before CI creates the tag.
7. Confirm Android publication and the TestFlight upload separately.
8. Submit the iOS build for public App Store review through App Store Connect.

Preparation does not create a tag or dispatch the release workflow.
No target stable binary, TestFlight upload, Android publication, or App Store submission has been produced by this preparation.
Physical-device acceptance has not been verified in this preparation.
The release workflow uploads iOS builds to TestFlight; it does not publish them to the public App Store.
